단위 mm · 도면은 실제 크기(1:1)

도면 설정

자유선은 스냅 없이 그려지고, 직선·사각형·벽체·치수는 수치 격자에 맞춰집니다.

손그림 밑그림

PNG/JPG를 불러온 뒤 두 지점을 찍고 실제 거리(mm)를 입력하면 크기가 맞춰져요. 손그림은 DXF에 포함되지 않으므로 별도로 보관하세요.

선택 객체 · 정확한 치수

‘선택/이동’ 도구로 그린 선이나 사각형을 선택하면 좌표와 치수를 mm로 수정할 수 있어요.

프로젝트

작업 저장은 JSON 파일로, AutoCAD 전달은 DXF로 저장해요. 인터넷 없이도 동작하도록 만든 단일 HTML 파일입니다.

초기 설계 보조 도구입니다. 구조·법규·정밀치수 검토, 네이티브 DWG 작성, BIM 기능은 제공하지 않습니다.
